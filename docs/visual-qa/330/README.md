## 설계와 이미지 검토

- 모바일 공지를 전폭으로 배치하고 제목을 14px·최대 두 줄로 표시했다. 날짜와 새 공지 표시는 독립된 공간을 유지한다. 마스코트를 작게 내려 통계 진입점과 같은 행에 배치해 공지 폭을 확보했다.
- 태블릿 대회 목록을 두 열로 구성하고 모바일 카드 높이·제목·기간·액션 간격을 조정했다. 동일한 4개 대회 fixture에서 전체 페이지 높이는 모바일 3009→2662px, 태블릿 2916→2130px였다. 이는 콘텐츠 배치의 측정값이며 로딩 성능 개선 수치가 아니다.
- 첫 After에서 3번 카드의 원형 장식이 모바일 CTA와 교차해 오른쪽 위로 옮기고 재촬영했다. 최종 이미지에서 텍스트와 장식의 영역이 분리됨을 확인했다.
- 1440px에서는 기존 두 열 대회·아카이브·사이드바 위계를 유지한다. 새 전역 토큰이나 별도 카드 시스템을 만들지 않았다.

## 상태와 상호작용

기본 공개 화면 13장과 홈 추가 상태 13장을 직접 검토했다. 1440·768·390px 기본 화면, 모바일 긴 공지·loading/empty/error·재시도, 마스코트 hover/focus, 태블릿 대회 1·2·4개를 확인했다. 한글 폰트를 로드한 모든 캡처의 문서 가로 넘침은 0px이었다.

대회가 전혀 없는 상태에서 안내가 없던 부분을 보완했고, 팝오버의 한글 어절 줄바꿈을 정리한 뒤 해당 두 화면을 재촬영했다. 정상 애니메이션에서는 비활성 버튼에 먼저 focus를 시도해 포커스가 유실되는 문제가 재현되어, 전환 종료 후 활성화된 버튼으로 이동하도록 수정했다. 정상·축소 모션의 왕복과 초기 진입 시 포커스를 빼앗지 않는 동작을 확인했다.

## 근거와 한계

최근 10/8·10/12 회의에는 이 홈 배치의 새 정책 결정이 없다. 기존 OPUS `EditorialHome.css` 테마와 실제 화면, `src/index.css` 토큰을 기준으로 개선했다. Renewal의 SCREENS `14:6`·ARCHIVE `14:11`에는 일치하는 공개 홈 최종 node가 확인되지 않았다. [Header 14:90](https://www.figma.com/design/HbyxwchvTkzD4pbtdjCHkg/OPUS-Renewal?node-id=14-90)·[Button 14:73](https://www.figma.com/design/HbyxwchvTkzD4pbtdjCHkg/OPUS-Renewal?node-id=14-73)을 공통 요소의 참고로 확인했으며 Figma 최종 화면의 재현을 주장하지 않는다.

QA #314는 아직 develop에 병합되지 않았다. 준비·검증된 기존 QA checkout에서 `VISUAL_QA_BASE_URL`로 이 독립 브랜치의 MSW 서버를 검사했으며 QA 코드를 복제하지 않았다. 샘플 배너·과거 날짜는 fixture이고, 실제 운영 데이터·백엔드 통합 및 모든 브라우저/보조기기 조합까지 검증한 것은 아니다. 사이드바·헤더의 별도 개선은 #304 범위다.
