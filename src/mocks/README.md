# #307 알림 MSW 확인

```sh
npm run dev:mock
```

출력된 로컬 주소의 `/signin`에서 로그인한 뒤, 우측 상단 프로필 → **알림**을 연다.
첫 방문의 회원가입 안내는 확인 후 닫는다.

| 계정                    | 비밀번호 | 확인 범위                                             |
| ----------------------- | -------- | ----------------------------------------------------- |
| `test@pusan.ac.kr`      | `test`   | 제출·피드백·마감 알림, 팀원에게 전달된 지정·해제 알림 |
| `professor@pusan.ac.kr` | `test`   | 단일·복수 팀 지정, 지정 해제, 잘못된 팀·대회 ID       |
| `mentor@pusan.ac.kr`    | `test`   | 멘토 지정·해제                                        |

- 학생: 기획서는 `submissionItemId=11`, 최종 보고서는 `12`가 펼쳐져야 한다.
- 교수/멘토: 단일 팀 지정은 103번 팀, 복수 팀 지정은 기존 기본 목록으로 이동한다.
- 지정 해제: 담당 목록에 없는 104번 팀의 공개 페이지로 이동한다.
- 지도 활동: 초안과 PDF 첨부파일을 추가하고 알림을 통해 다른 팀으로 이동했다 돌아와도 보존되어야 한다.
- 피드백 본문에 `[실패]`를 넣어 저장하면 500 응답을 반환한다. 초안·첨부파일이 남는지 확인한 뒤 해당 문자열을 지우고 저장한다.
- 존재하지 않는 제출 항목, 권한 없는 팀, 중복 ID, 외부 URL 알림으로 잘못된 대상이 열리지 않는지 확인한다.
- 개별 읽음과 모두 읽음은 목록과 프로필의 읽지 않은 개수에 반영된다.

`mock` 모드는 API 주소를 동일한 로컬 origin으로 설정한다. 미구현 API는 501을 반환한다.
시나리오 핸들러는 MSW가 활성화되면 기존 핸들러보다 먼저 적용된다.
기존 `npm run dev`도 `VITE_USE_MSW=true`이면 같은 알림 데이터를 제공한다.
알림 읽음·피드백 저장 상태는 메모리에만 보관하며 **새로고침하면 초기화**된다.
제출물 업로드·확인 메모 변경·첨부파일 다운로드는 이번 시나리오 범위에 포함하지 않는다.
